# Immersive Deck

A cinematic, browser-only 3D presentation workspace. Import `.pptx` and `.pdf` files and extract the complete available text from every slide/page directly in the browser.

## Features

- 3D-inspired stage with depth, glow, orbiting geometry and presentation mode
- Full text extraction from PPTX slide XML and PDF pages
- Search across the imported deck
- Keyboard navigation: `←` / `→`, `Space`, `F`, `Escape`
- GitHub Pages deployment via Actions
